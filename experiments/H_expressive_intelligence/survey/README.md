# H2 survey instrument (v0.1, researcher pilot)

`index.html` implements the procedure in `prereg/H2_PROTOCOL.md` §4 as a single local page.

**Status: researcher pilot only.**
- No participant has been recruited.
- Ethics determination and the user's authorization (protocol §1) are still required before anyone else takes it.
- Responses from the researcher's own run are feedback on the instrument, never study data. They are not analysed as
  H2 results.
- The researcher has also seen labelled clips, so their answers are not blind.

## Running it

Open `index.html` in a desktop browser. It reads `forms.js` and the clips in `../videos/h1/` by relative path.
If the browser blocks local files, serve the folder instead:

```
python -m http.server 8765 --bind 127.0.0.1 --directory experiments/H_expressive_intelligence
```

then go to `http://127.0.0.1:8765/survey/`.

Progress is kept in the browser while a session is open. At the end, **Save my responses** downloads a JSON file.
Pilot files go in `pilot_responses/`, which is git-ignored.

## What the page does

**Flow:**
1. two practice clips (watch only);
2. the main block;
3. a debrief;
4. feedback questions about the survey itself.

**Per clip:**
- The questions unlock after the clip has played to the end once; replays are allowed.
- Forced choice: the six style words in a per-session random order, then "neutral / none of these" last.
- Six 0–100 sliders, each of which must be touched.
- Three 7-point statements.
- Optional free text.

**Forms** are generated by `scripts/h2_survey_forms.py` from seed partition H2/P (20 per length). The page picks one at
random, or uses `?form=N`. Forms list file names only, so the style key never reaches the page.

**Recorded per clip:**
- the response values;
- the number of plays;
- time to the first end of the clip;
- response time;
- a timestamp.

## Implementation choices the protocol leaves open

These must be confirmed or changed before the protocol is frozen.

1. **Training vs main neutral clips.** Training uses the two neutral clips with seed index 1. The main block uses the
   two with seed index 0, so no clip is seen twice. As a result the main block has 2 neutral clips, not 4.
2. **Full form (36 main clips):**
   - each designed style 4 times (2 native and 2 matched speed, one per geometry each);
   - 2 neutral;
   - 10 of the 20 random-style clips.
3. **Attention checks.** Random-style clips not otherwise in that form, shown with a written instruction ("choose
   curious, energy slider to 0"). The protocol mentions "an instruction clip", but none was rendered.
4. **"Neutral / none of these" is fixed last.** The protocol says option order is randomised; only the six style
   words are shuffled.
5. **Quick form (12 clips + 1 check).** Pilot only, not in the protocol: each designed style once, 2 neutral, 4 random.
6. **Session length.** The full form has about 17 minutes of video (mean clip 27 s), so the session takes about 40
   minutes, not the ≈ 25 minutes the protocol estimates. Fixing this means shorter clips, fewer clips per participant,
   or a revised estimate and payment.
7. **Exclusion rules** (completion time, straight-lining) are not yet fixed. The page records the timing data they
   will need.
